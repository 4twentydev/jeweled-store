# JWLD Product Image Prompt Template

Use this when generating more product images in the same style:

```txt
Create a clean luxury ecommerce product photo of a handmade JWLD [PRODUCT TYPE]. The item is decorated with [COLOR / MATERIAL / PATTERN], including [CHARMS / LETTER BEADS / DESIGN DETAILS]. Center the product upright on a warm off-white studio background with soft diffused lighting, realistic shadow beneath the product, sharp crystal/bead detail, and a minimalist boutique product-card style. Square 1:1 composition, no hands, no text overlay, no watermark, no clutter, no extra props. Keep the product shape and decoration accurate to the reference photo.
```

For app consistency:

```txt
Match the JWLD product-card style: warm cream background, centered product, soft shadow, slight front-facing angle, crisp stones, realistic metal lighter top, clean ecommerce lighting, square crop, premium handmade accessory look.
```

Recommended export pattern:

```txt
jwld-[sku]-[short-product-slug].webp
```
