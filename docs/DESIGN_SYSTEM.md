# Design System

### Visual Direction
Almost black: #050505
Soft black: #101010
Almost white: #f7f4ef
Muted white: #e9e4dc
Soft gray: #9a948a
Accent: random controlled luxury pop

### Accent Colors
const accents = [
  "#C8A2C8", // soft lilac
  "#D4AF37", // muted gold
  "#FF5CA8", // jewel pink
  "#7DF9FF", // electric blue
  "#B6FF7D", // acid lime
];

### Accent Color Rules
1 accent per page load
Small underline
Button glow
Product badge
Tiny corner gradient
Cart count

### Design Musts
Do not turn the whole site neon. The product already has sparkle. The site should feel expensive and restrained.
